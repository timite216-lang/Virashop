ViraShop — boutique e-commerce statique

Fichiers :
- index.html : boutique
- style.css : design responsive
- script.js : produits, recherche, filtres, panier et commande WhatsApp

Le numéro WhatsApp est configuré sur 07 20 13 61 26.

IMPORTANT :
Le site fonctionne sans serveur et sans abonnement. Le paiement en ligne réel n'est pas encore branché : le client choisit son moyen de paiement puis la commande est envoyée sur WhatsApp. Les prix et produits de démonstration sont à remplacer par tes informations réelles.

Mise en ligne gratuite :
1. Créer un compte GitHub.
2. Créer un dépôt nommé virashop.
3. Importer index.html, style.css et script.js.
4. Activer GitHub Pages dans Settings > Pages.
